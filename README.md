# 寿司ダッシュ

キモ可愛いシャリになって寿司レーンを駆け抜ける、ブラウザで遊べる3Dランゲームです。スマホ・PCどちらでも、下のURLを開くだけで遊べます。

公開URL: https://lee3izmsd.github.io/sushi-dash/
（かんたん・練習モード追加前の版：https://lee3izmsd.github.io/sushi-dash/v75/ ）

- STAGE 1「金箔の大広間」→ STAGE 2「夜桜の料亭」→ STAGE 3「天空の回転寿司タワー」
- スマホ：スワイプで移動、タップでジャンプ・斬撃、下スワイプでスライディング
- PC：A/D・←→で移動、Spaceでジャンプ、Sでスライディング、Shift＋方向でドリフト、Eでガリ覚醒

このゲームは three.js（MIT License）を CDN（jsDelivr）から読み込んでいます。
